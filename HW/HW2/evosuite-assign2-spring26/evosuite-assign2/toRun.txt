This works on pyrite. On your own machine you may need to set up Java 11 and create these aliases.


>java11c Tutorial_Stack/src/main/java/tutorial/*.java

>jav11a -jar evosuite-1.2.0.jar -projectCP Tutorial_Stack/src/main/java -class tutorial.Stack

Test cases will be in the evosuite-tests directory
Reports will be in the evosuite-reports directory

export CLASSPATH=.:evosuite-tests:lib/junit-4.13.jar:lib/hamcrest-core-1.3.jar:Tutorial_Stack:evosuite-standalone-runtime-1.2.0.jar
